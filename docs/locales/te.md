# Telugu resources

Code: `te`. This locale preserves source-provided words, commands, orientation prompts, and object labels. The new application interface remains English. The presence of a translation does not demonstrate cultural equivalence or clinical validation.

## Review procedure

Compare `data/locales/te.json` and `data/wordlists/te.json` with the legacy source. Obtain bilingual subject review of wording, familiarity, dialect, and target/distractor overlap. Document reviewer and version before clinical use.
