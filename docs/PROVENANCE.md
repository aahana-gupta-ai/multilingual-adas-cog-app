# Provenance and authorship

This repository contains material from two stages of the project:

1. **Original research and earlier application work** — the research question, project direction, multilingual assessment work, and the preserved earlier web application in `legacy/`.
2. **Public documentation layer** — later demonstration code, tests, synthetic examples, and documentation assembled to make the project easier to inspect and reproduce publicly.

The public repository was consolidated in **October 2026**, after the underlying research had already begun.

AI-assisted development tools were used in parts of the later public documentation/demo layer. Those additions are not presented as recovered original production code.

No patient-identifiable data is included in this repository.
