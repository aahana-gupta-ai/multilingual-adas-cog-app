# Ideational praxis

This module records a **demonstration observation count**, from 0 to 5. It does not calculate an ADAS-Cog subscore.

Walk through the source letter-and-envelope sequence with fictional details.

## Resources

- Definition: `data/tasks/ideational-praxis.json`
- Domain validator: `src/tasks/ideational-praxis.js`
- Synthetic response: `examples/task-responses/ideational-praxis.json`
- Boundary scenarios: `data/scenarios/ideational-praxis.json`

A blank response is `null` with status `missing`. Zero is a recorded count and remains distinct from a missing response. Real administration and scoring require a separately reviewed protocol.
