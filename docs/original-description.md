# Multilingual ADAS-Cog App

**The dementia memory test, in the patient's own language.**

![Demo](docs/demo.gif)

## The problem

The ADAS-Cog is one of the most widely used memory tests in dementia research. It was designed in English, around English word lists. My first study (12 patients, published in *Bioinformation*) showed how cultural and language differences can affect Indian patients' scores. To test this at scale, I needed to give the same test reliably in several languages. No tool did that.

## What I built

An app that gives the ADAS-Cog in **4 Indian languages** and records every response in one consistent format, so scores can be compared across languages.

## Result

It collected the data for all **120 patients** in my study with Prof. Vijay Kumar Chattu, now under review at the *Journal of Clinical Neuroscience*.

## Built with

**Manus** (AI agent platform), May 2026. The test design, language versions and patient testing are my own work.

## My role

I designed what the app does and how each language version works, built it with Manus, tested it, and used it to collect the study's data.

## Data

No patient data is stored here; the study data is confidential under its ethics approval. [`sample-data/`](sample-data) has a synthetic example and a data dictionary.
